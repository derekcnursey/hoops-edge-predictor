# Conference Tournament Analysis — 2026

## Methodology

Model probabilities derived from **50,000 Monte Carlo simulations** per conference tournament using the production regressor with symmetric neutral-site averaging. Each simulation plays out the **real tournament bracket** with proper bye structures, stepladder formats, and correct official seedings from conference announcements.

**Model Odds** are American-format moneyline equivalents of the model win probability.
